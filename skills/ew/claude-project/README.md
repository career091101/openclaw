# Elliott Wave JP225 — Claude Project セットアップ

Claude iOS / Mac アプリでエリオット波動分析を使うための手順。

## セットアップ

1. **claude.ai** にログインし、左サイドバーから「Projects」を開く
2. 「New Project」をクリック、名前を「Elliott Wave JP225」に設定
3. **Custom Instructions** に `instructions.md` の内容を貼り付ける
4. **Project Knowledge** に以下3ファイルをアップロード:
   - `knowledge-core.md`
   - `knowledge-patterns.md`
   - `knowledge-theory.md`
5. iOS / Mac の Claude アプリで該当 Project を開く

## 使い方

### フル分析

```
JP225のエリオット波動分析をお願いします。

現在値: ¥38,500
直近の日足データ:
02/21 始値38,200 高値38,800 安値38,100 終値38,500
02/20 始値38,600 高値38,700 安値38,100 終値38,200
...
```

### 波動カウント特化

```
波動カウントを詳細に分析してください。

[価格データを貼り付け]
```

### シナリオ生成

```
現在の状況から複数のシナリオを生成してください。

現在値: ¥38,500
直近高値: ¥40,000 (12/15)
直近安値: ¥37,000 (11/20)
```

## 制約事項（CLI版との違い）

- **データ自動取得不可**: ユーザーが価格データを手動で提供する必要あり
- **ファイル永続化なし**: PDCAレビューは会話内で完結
- **Slack通知なし**: 分析結果の通知機能は使えない
- **ツイート統合なし**: @jewri225 のツイートは手動でコピペ
- **チャート画像**: スクリーンショットを手動アップロード

## 推奨データソース

- **TradingView**: JP225 の日足・週足チャートをスクリーンショット
- **Yahoo Finance**: `^N225` で OHLC データをコピー
- **IG証券アプリ**: 日本225 のチャート画面をスクリーンショット
