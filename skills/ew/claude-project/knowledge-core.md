# エリオット波動分析 — コアナレッジ

## 1. 役割と原則

エリオット波動理論を用いてJP225の波動分析を行う。提供する情報:

1. 現在の波動フェーズの特定
2. 上昇・下落の方向性予測
3. 想定される値幅・到達目標
4. 複数シナリオと確率評価

### 3つの絶対ルール

| #   | ルール                           | 説明                                                       |
| --- | -------------------------------- | ---------------------------------------------------------- |
| 1   | **第2波は第1波の起点を割らない** | 第2波が第1波の始点を下回った場合、別の波動構造             |
| 2   | **第3波は最短にならない**        | 推進波1・3・5の中で第3波が最短ならカウント誤り             |
| 3   | **第4波は第1波と重ならない**     | 第4波が第1波の価格帯に入った場合、ダイアゴナルか別パターン |

### ディグリー体系（8段階）

| ディグリー               | 推進波記号          | 修正波記号      |
| ------------------------ | ------------------- | --------------- |
| グランドスーパーサイクル | ((I))((II))...((V)) | ((A))((B))((C)) |
| スーパーサイクル         | (I)(II)...(V)       | (A)(B)(C)       |
| サイクル                 | I II III IV V       | A B C           |
| プライマリー             | ① ② ③ ④ ⑤           | Ⓐ Ⓑ Ⓒ           |
| インターミディエット     | (1)(2)(3)(4)(5)     | (A)(B)(C)       |
| マイナー                 | 1 2 3 4 5           | A B C           |
| ミニュット               | i ii iii iv v       | a b c           |
| ミニュエット             | (i)(ii)(iii)(iv)(v) | (a)(b)(c)       |

## 2. 呼び出しモード

### モード1: フル分析（デフォルト）

3セクション（現状分析・トレード戦略・リスク管理）の完全出力。

### モード2: 波動カウント特化

大局観、詳細カウント表、絶対ルール検証、フィボナッチ整合性チェック、サブ波分析。

### モード3: シナリオ生成

複数シナリオ一覧、各シナリオ詳細、判断フロー、判断基準サマリー、次回確認ポイント。

---

## 3. 出力フォーマット

### セクション1: 現状分析と波動カウント

波動位置（対象・時間軸・分析期間・現在位置・トレンド方向）、詳細カウント表、階層的サブ波分解（ツリー表記）を含む。

**ツリー出力テンプレート:**

```
Primary ⑤ (48,644 → 58,015) +9,371pt  インパルス
├── (1) 52,655 → 54,783  +2,128pt  インパルス
│   ├── i: 52,655 → 53,500  +845pt
│   ├── ii: 53,500 → 53,100  -400pt  (47.3%リトレース)
│   ├── iii: 53,100 → 54,400  +1,300pt  ★最長波
│   ├── iv: 54,400 → 54,100  -300pt  (23.1%リトレース)
│   └── v: 54,100 → 54,783  +683pt
├── (2) 54,783 → 52,655  -2,128pt  ジグザグ a-b-c
├── (3) 52,655 → 58,015  +5,360pt  エクステンド ★
├── (4) 58,015 → ~56,800  -1,215pt  ダブルコンボ w-x-y
└── (5) ~56,800 → ?  [進行中?]
```

**ツリー表記ルール:**

1. 各波に値幅とフィボナッチ比率を記載
2. 修正波の種類を明記
3. 最長推進波は必ず1階層深く分解（★マーク）
4. 波の内部構成（5波 or 3波）を確認
5. 確定していない波は `?` をつける

絶対ルール検証とフィボナッチ整合性チェックを必ず含める。

### セクション2: トレード戦略

シナリオ一覧表（確率・方向・エントリー・TP・SL・R:R比）、各シナリオ詳細、シナリオ判断フロー。

### セクション3: リスク管理

ポジションサイジング、監視ポイント、注意事項、次回確認ポイント。

## フィボナッチ比率ガイド

### 基本比率

| 比率  | 値     | 用途                  |
| ----- | ------ | --------------------- |
| 0.236 | 23.6%  | 浅い調整              |
| 0.382 | 38.2%  | 標準調整（4波）       |
| 0.500 | 50.0%  | 中間調整（2波）       |
| 0.618 | 61.8%  | 深い調整（2波）       |
| 0.786 | 78.6%  | 最深調整              |
| 1.000 | 100%   | 等倍                  |
| 1.618 | 161.8% | 黄金比拡大（3波目標） |
| 2.618 | 261.8% | 強い3波目標           |

### リトレースメント（調整目標）

**第2波**: 50%〜61.8%（78.6%超でカウント疑問、100%超でルール違反）
**第4波**: 38.2%〜50%（61.8%でダイアゴナル可能性）
**修正B波**: ジグザグ50%〜61.8% / フラット78.6%〜100% / 拡大フラット100%超

### エクステンション（拡大目標）

**第3波**: 161.8%〜261.8%（第1波基準）
**第5波**: 100%等倍 / 61.8% / 161.8%（第1波基準）
**C波**: 100%〜161.8%（A波基準）

### 計算方法

- リトレースメント: `調整目標 = 高値 - (高値 - 安値) × 比率`
- エクステンション: `拡大目標 = 起点 + (基準波値幅) × 比率`

### JP225 値幅目安（日足）

| 波動      | 典型的な値幅  |
| --------- | ------------- |
| 1日の動き | 200-500円     |
| 1波       | 1,000-3,000円 |
| 3波       | 1,600-8,000円 |
| 5波       | 1,000-3,000円 |

## 分析前チェックリスト

### 時間軸の確認

- 分析対象の時間軸を決定した（日足/4時間足/1時間足）
- 上位時間軸のトレンドを確認した
- 下位時間軸でサブ波を確認した
- ログスケール表示で分析している

### 3つの絶対ルール検証

1. 第2波の安値 > 第1波の起点
2. 第3波 > 第1波 または 第3波 > 第5波
3. 第4波の安値 > 第1波の高値

### 波動構成確認

| パターン       | 構成      |
| -------------- | --------- |
| インパルス     | 5-3-5-3-5 |
| ダイアゴナル   | 3-3-3-3-3 |
| ジグザグ       | 5-3-5     |
| フラット       | 3-3-5     |
| トライアングル | 3-3-3-3-3 |
| W3（ダブル3）  | 3-X-3     |

### フィボナッチ整合性チェック

- 第2波: 50%〜61.8%か？ 78.6%超えていないか？
- 第3波: 161.8%到達？200%？261.8%？
- 第4波: 38.2%付近か？50%超えていないか？
- 第5波: 第1波と等倍？61.8%？161.8%？

### よくあるカウントミス

- ダイアゴナルとトライアングルの混同（トレンドラインの向き確認）
- ダイアゴナル2波にフラットが出る可能性
- トライアングルA波にトライアングルを入れていないか
- W3のY波にダイアゴナルを入れていないか（推進波は出ない）
- ジグザグを2箇所に入れていないか（1箇所のみ）

### シナリオ分岐チェック

- 現在の波動位置を特定した
- 別の波動カウントを用意した
- シナリオ切り替え条件を明確にした
- 確率評価を行った
