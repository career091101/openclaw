# エリオット波動 — パターンリファレンス

---

## インパルス（Impulse）

**推進波**の代表格。5波構成（1-2-3-4-5）でトレンド方向に進む。

### 波動構成

```
5 - 3 - 5 - 3 - 5
│   │   │   │   └─ 5波: 推進波
│   │   │   └───── 4波: 修正波
│   │   └───────── 3波: 推進波（必ずインパルス）
│   └───────────── 2波: 修正波
└───────────────── 1波: 推進波
```

### 3つの絶対ルール

| #   | ルール                   | 違反時                         |
| --- | ------------------------ | ------------------------------ |
| 1   | 2波は1波の始点を割らない | インパルスではない             |
| 2   | 3波は最短にならない      | インパルスではない             |
| 3   | 1波と4波は重ならない     | インパルスではない（例外あり） |

### ガイドライン

- **チャネリング**: 1-3終点と2-4終点が平行
- **1波と5波の等距離**: 延長がなければほぼ同サイズ
- **2波の深いリトレース**: 50%〜78.6%
- **4波の浅いリトレース**: 38.2%程度
- **オルタネーション**: 2波と4波は異なる性質

### 延長（エクステンション）

| 延長波  | 頻度 | 特徴                      |
| ------- | ---- | ------------------------- |
| 1波延長 | 稀   | 見分けにくい              |
| 3波延長 | 最多 | 最も一般的                |
| 5波延長 | 次点 | 完成後に2波終点まで急反転 |

## ダイアゴナル（Diagonal）

**推進波**の一種。5波構成だが全て修正波（3-3-3-3-3）で構成される。

### 2つの外観

| 型         | 特徴                 |
| ---------- | -------------------- |
| **収縮型** | だんだん幅が狭くなる |
| **拡大型** | だんだん幅が広がる   |

> **トライアングルとの違い**: ダイアゴナルは上下のトレンドラインが**同じ方向**を向く

### 出現位置（5箇所のみ）

| 位置            | 呼称                     |
| --------------- | ------------------------ |
| インパルスの1波 | リーディングダイアゴナル |
| インパルスの5波 | エンディングダイアゴナル |
| ジグザグのA波   | リーディングダイアゴナル |
| ジグザグのC波   | エンディングダイアゴナル |
| フラットのC波   | エンディングダイアゴナル |

### 副次波の構成

| 波        | 基本       | 例外                   |
| --------- | ---------- | ---------------------- |
| 1, 3, 5波 | ジグザグ系 | -                      |
| 2波       | ジグザグ系 | **フラットが割とある** |
| 4波       | ジグザグ系 | フラット、W3が稀に出る |

> 2波と4波にトライアングルは出ない

### フェイラーのルール

| ダイアゴナル       | フェイラー   |
| ------------------ | ------------ |
| 収縮型エンディング | 認められる   |
| 拡大型エンディング | 認められない |
| 収縮型リーディング | 認められない |
| 拡大型リーディング | 認められない |

### 完成後の動き

- **エンディング**: 2波終点まで急速に戻す
- **リーディング**: 4波終点まで急速に戻す（浅い）
- **完成確認**: 2波終点を超えた時に事後的に確定

## ジグザグ（Zigzag）

**修正波**の代表格。5-3-5の急な調整パターン。

### 波動構成

```
5 - 3 - 5
│   │   └─ C波: 推進波（インパルスまたはダイアゴナル）
│   └───── B波: 修正波（あらゆるタイプ）
└───────── A波: 推進波（インパルスまたはダイアゴナル）
```

### 絶対ルール

1. A波とC波は**必ず5波動**
2. B波は**必ず3波動**
3. **B波はA波始点を超えない**（一瞬でもダメ）

### ガイドライン

- チャネルになりやすい
- C波はA波より傾きが緩やか
- C波自体/C波の5波がダイアゴナルになりやすい
- B波はA波を38.2%〜78.6%リトレース
- C波はA波終点を超えて終わる（フェイラー可）

### 派生形

| 波形                 | 構成                           |
| -------------------- | ------------------------------ |
| **ダブルジグザグ**   | ジグザグ-X-ジグザグ            |
| **トリプルジグザグ** | ジグザグ-X-ジグザグ-X-ジグザグ |

### 発展パターン

小さいジグザグが出た場合: (1)ダブルジグザグへ発展 (2)フラットのA波として発展 (3)インパルスの途中かもしれない

## フラット（Flat）

**修正波**の一種。3-3-5の横ばい調整パターン。

### 波動構成

```
3 - 3 - 5
│   │   └─ C波: 推進波（インパルスまたはダイアゴナル）
│   └───── B波: 修正波（何でもOK）
└───────── A波: 修正波（トライアングル以外）
```

### ジグザグとの違い

| 項目            | ジグザグ          | フラット            |
| --------------- | ----------------- | ------------------- |
| 構成            | 5-3-5             | 3-3-5               |
| 最初の波        | 推進波            | 修正波              |
| B波のリトレース | A波始点を超えない | 原則A波始点まで戻す |

### 絶対ルール

1. A波とB波は必ず3波動（修正波）
2. C波は必ず5波動（推進波）
3. A波にトライアングルは出ない
4. B波は最低でもA波を90%リトレース

### バリエーション

| 種類                   | 特徴                                           |
| ---------------------- | ---------------------------------------------- |
| **レギュラーフラット** | B波がA波始点近くまで戻る                       |
| **拡大型フラット**     | B波がA波始点を超え、C波がA波終点を超える       |
| **ランニングフラット** | C波がA波終点まで届かない（強いトレンドの前兆） |
| **C波巨大化フラット**  | エリオット命名「エンラージメントコレクション」 |

### 実践ポイント

- C波は必ず5波動（なければフラットではない）
- ランニングフラット後は強い推進波（延長の可能性高い）
- B波の138%ルールは無視してよい（200%超のリトレースあり）

## トライアングル（Triangle）

**修正波**の一種。3-3-3-3-3の5波動構成（A-B-C-D-E）。

### 波動構成

```
3 - 3 - 3 - 3 - 3
│   │   │   │   └─ E波: 修正波
│   │   │   └───── D波: 修正波
│   │   └───────── C波: 修正波
│   └───────────── B波: 修正波（何でもOK）
└───────────────── A波: 修正波（トライアングル出ない）
```

### 4つのバリエーション

| 型             | 特徴                                   |
| -------------- | -------------------------------------- |
| **収縮型**     | 幅がだんだん狭くなる（最も一般的）     |
| **ランニング** | B波がA波始点を超える（収縮型の40%）    |
| **バリア型**   | BDラインが水平（株価はBD方向に抜ける） |
| **拡大型**     | 幅がだんだん広がる（性質が異なる）     |

### 絶対ルール

1. 各副次波は必ず修正波
2. A波にトライアングルは出ない
3. C波はA波終点を超えて動かない（収縮型）
4. E波はC波終点を超えて動かない
5. D波はB波終点を超えて動かない

### 出現位置

- インパルスの4波（最も一般的）
- ジグザグのB波
- ダブルジグザグのX波
- W3の最後のアクション波（W波には出ない）

### スラスト

4波にトライアングル出現 → 5波は**スラスト**（短時間で終了）

- 5波の大きさ ≒ トライアングルの最大範囲
- スラスト範囲を超えたら**5波延長の前兆**

### カウントミス例

1. ダブルジグザグのX波だった
2. C波/D波がダブルジグザグだった
3. 実はダイアゴナルの一部だった

## 複合修正（Complex Corrections）

単純な修正波（ジグザグ、フラット、トライアングル）が2つまたは3つ連結したもの。

| 名称                   | 構成      |
| ---------------------- | --------- |
| **ダブルスリー（W3）** | W-X-Y     |
| **トリプルスリー**     | W-X-Y-X-Z |

### W3のルール

- **W波**: トライアングル以外のシングル修正波
- **X波**: あらゆる修正波（何でもOK）
- **Y波**: 拡大型トライアングル以外のシングル修正波
- **ジグザグは1箇所のみ**: W波かY波のどちらか1つだけ

### W3は5種類しかない

| #   | W波      | Y波            |
| --- | -------- | -------------- |
| 1   | ジグザグ | フラット       |
| 2   | ジグザグ | トライアングル |
| 3   | フラット | フラット       |
| 4   | フラット | ジグザグ       |
| 5   | フラット | トライアングル |

### X波の実態

プレクター説では「単純なジグザグが多い」だが、実際は**複雑で大きいことが多い**。

### カウント手順

1. 両端にシングル修正波を見つける
2. 残った中心部がX波
3. X波は複雑でOK（詳細は後回しでも可）
