# エリオット波動 — 理論リファレンス

---

## 第1章: エリオット波動の基本

### 重要書籍（4冊）

1. **1938年論文** - エリオットの原著
2. **自然の法則** - エリオットの理論書
3. **ボルトンの本** - 初期の解説書
4. **プレクターの本** - 現在の標準テキスト（最重要）

### 波動の基本構造

**5波動-3波動サイクル:**

```
上昇5波: 1 → 2 → 3 → 4 → 5
修正3波: A → B → C
完全サイクル = 5 + 3 = 8波
```

### アクション波とリアクション波

| 種類               | 定義                                                   |
| ------------------ | ------------------------------------------------------ |
| **アクション波**   | メジャートレンドと同じ方向（一回り大きな波動と同方向） |
| **リアクション波** | メジャートレンドと逆方向                               |

> 「上向き=アクション」ではない。下落トレンド中の下落波もアクション波になりうる。

### 波動パターンの分類

**推進波（Motive Wave）:**

- インパルス: 5-3-5-3-5構成
- ダイアゴナル: 3-3-3-3-3構成

**修正波（Corrective Wave）:**

- ジグザグ: 5-3-5（急な調整）
- フラット: 3-3-5（横ばい調整）
- トライアングル: 3-3-3-3-3

**複合修正波:** ダブルスリー(W-X-Y) / トリプルスリー(W-X-Y-X-Z)

### 拡大型フラットの注意点

- 上昇波動1波目のインパルスに見えて、実は拡大型フラットのC波の可能性
- B波が3波動か5波動かで解釈が変わる

## 第2章: 推進波（インパルス）

### 3つのルール

1. **2波は1波の起点を割らない**
2. **3波は最短にならない**（延長する可能性が高い）
3. **4波は1波と重ならない**（ダイアゴナルの場合は例外あり）

### フラットのバリエーション

| パターン           | 特徴                                           |
| ------------------ | ---------------------------------------------- |
| レギュラーフラット | B波がA波の始点近くまで戻る                     |
| 拡大型フラット     | B波がA波の始点を超え、C波がA波の終点を超える   |
| ランニングフラット | C波がA波の始点を下回らない（トレンド継続示唆） |
| C波巨大化フラット  | C波が延長してジグザグに近い形                  |

### 複合修正波

- **ダブルスリー**: W波 + X波 + Y波（ジグザグは1つだけが基本）
- **トリプルスリー**: W + X + Y + X + Z（トライアングルと類似）
- **X波**: 通常はジグザグ、あらゆる修正波になる可能性あり、1つ目のX波はトライアングルにならない

### オルタネーション

- 2波と4波は異なる形状になりやすい
- A波とB波もオルタネーションの傾向

## 第3章: 修正波

### 複合修正波の特徴

- 一般的に修正波は複雑で判断が難しい
- 複合修正波は特に難解で未解明な部分が多い
- トリプルスリーとトライアングルは類似（W-X-Y-X-Z形式とA-B-C-D-E形式）

### トレンドライン分析

- **上値ライン**: 1波終点と3波終点を結ぶ
- **下値ライン**: 2波終点を通る平行線
- **5波の終点目安**: 1波と3波の終点を結んだライン（スローオーバーもある）

### スローオーバーの注意点

- 収縮型ダイアゴナル/トライアングルでよく起こる
- あたかも新トレンドが始まったように見せかけ、その後逆のトレンドが始まる
- 4波の終点がトレンドラインを割り込む → 5波のスローオーバーの可能性

### トライアングル各波の特徴

- **A波**: 最初の下落波、投資家はまだ楽観的
- **B波**: 反発上昇、「もう一段高がある」という期待
- **C波**: 複雑化・長期化しやすい、横ばいになることが多い
- **D波**: 再び上昇、日経平均は上がるが個別銘柄は動かない
- **E波**: 最終波、ファンダメンタルズ的材料が出やすい、修正の最終局面

## 第4章: 波動の性格と長期カウント

### 各波の個性（投資家心理）

| 局面      | 特徴                                     | 投資家心理               |
| --------- | ---------------------------------------- | ------------------------ |
| **1-2波** | 悲観の中で生まれる上昇、出来高低下       | まだ疑心暗鬼             |
| **2-3波** | ファンダメンタルズを伴う本格的上昇       | 強気転換                 |
| **3-4波** | 押し目買いが入る下落、オルタネーション   | 強気継続                 |
| **4-5波** | 上昇基調継続                             | 楽観                     |
| **5-B波** | まやかしの上昇、高値超えられない銘柄多い | かなり強気だが実態は弱い |

### 4波のガイドライン

- 修正波の深さで終点のメドがつけやすい
- オルタネーションで2波と違う波形になりやすい

### NYダウのスーパーサイクル

- 1932年の世界恐慌安値からスタート
- 主要な安値: II波=世界大恐慌、②波=ブラックマンデー、④波=リーマンショック

### 修正波のシナリオ分岐

常に複数シナリオを考慮:

1. ジグザグシナリオ
2. フラットシナリオ
3. トライアングルシナリオ
4. 複合修正波シナリオ

## 第5章: ダイアゴナルと応用

### ダイアゴナルの基本

- 3-3-3-3-3（各波が3波構成）、収縮型と拡大型
- 出現位置: 5波目、C波、1波目（リーディング）

### トライアングル出現後の予測

- 直前のトレンド方向にアクション波
- 上昇目標 = トライアングルの最も大きな副次波と同じ大きさ

### v波完了確認戦略

- **買いポイント**: v波の始点（iv波の終点）まで反転したところ
- **上値ターゲット**: (iv)波の終点
- **損切りポイント**: (v)-v波の終点と想定したポイント
- 予想通りに上昇しない場合 → 想定誤りと判断

### 拡大フラットの注意

- (iv)波が実は拡大フラットだった可能性を常に考慮
- 予想と異なる動きに備え、複数シナリオを保持

## 第6章: トレード戦略

### リスク・リウォード・レシオ

- RRR = REWARD / RISK
- 大きな階層の波動完成を狙うほど有利

### エントリー手法

1. **できるだけ大きい波動の完成を狙う**（RRRで有利）
2. **インパルス4波終点超えでエントリー**（副次波の推進波完成を確認）

### 修正波判断のポイント

- 大きなインパルス出現 → 新トレンド開始の可能性高い
- どんな波形でも副次波は推進波で終わる

## 第7章: エリオット波動の源流

### オルタネーション

- インパルスの2波と4波が異なる波形になる現象
- フラットのA波とB波にも同様の習性

### ガイドライン一覧

- 波の延長、波の均等性、オルタネーション
- チャネリング、出来量、比率関係
- 修正波の深さ、波の個性
- ルールほど厳格ではないが、当てはまるシナリオほど正解になりやすい

### 価格修正と時間調整

- **価格修正**: 価格が大きく動く調整
- **時間調整**: 価格変動は小さいが時間がかかる調整

## FAQ（よくある質問）

**Q: 推進波と修正波の違いは？**
波の**形**による分類。推進波=インパルス/ダイアゴナル、修正波=ジグザグ/フラット/トライアングル。「アクション波/リアクション波」は**方向**による分類で別物。

**Q: フラクタルとは？**
部分と全体が自己相似の関係。どの時間軸でも同じルールが適用される。

**Q: ログスケールを使うべき理由は？**
変化率を正確に比較するため。特に長期チャートで重要。

**Q: 延長波とは？**
1波/3波/5波のいずれか1つが巨大化する現象。3波延長が最も多い。5波延長後は2波終点まで急反転。

**Q: ダイアゴナルとトライアングルの見分け方は？**
トレンドラインの向き。ダイアゴナル=同じ方向、トライアングル=逆方向。

**Q: ダイアゴナルの2波にフラットは出る？**
出る。プレクター本には「全てジグザグ」とあるが、実際は2波にフラットがしばしば出る。

**Q: フラットのB波のリトレース率は？**
最低90%がルール。138%ルールは無視してよい。200%超のリトレースもある。

**Q: A波にトライアングルは出る？**
出ない。フラットのA波も同様。修正波の「最初のアクション波」にはトライアングルは出ない。

**Q: 4波トライアングル後の5波は？**
スラスト（短時間で終了）になりやすい。大きさはトライアングルの最大範囲と同等。

**Q: W3の種類は？**
5種類のみ。ジグザグ-フラット / ジグザグ-トライアングル / フラット-フラット / フラット-ジグザグ / フラット-トライアングル。W波にトライアングルは出ない、ジグザグは1箇所のみ。

**Q: X波は単純なジグザグが多い？**
間違い。プレクター説とは異なり、X波は複雑で大きいことが多い。

**Q: フィボナッチ比率は厳密？**
アバウトでOK。0.618ぴったりでなくても、0.59〜0.63程度でもフィボナッチ関係とされる。

## 用語集

### 基本用語

| 用語           | 定義                                      |
| -------------- | ----------------------------------------- |
| インパルス     | 5-3-5-3-5の5波動構成、3原則を満たす推進波 |
| ダイアゴナル   | 3-3-3-3-3の5波動構成、収縮型/拡大型       |
| ジグザグ       | 5-3-5の修正波、急な調整                   |
| フラット       | 3-3-5の修正波、横ばい調整                 |
| トライアングル | 3-3-3-3-3の修正波、収縮型/拡大型          |

### 構造関連

| 用語                           | 定義                                         |
| ------------------------------ | -------------------------------------------- |
| 延長（エクステンション）       | 1波/3波/5波のいずれかが巨大化                |
| オルタネーション               | 2波と4波が異なる形状になる現象               |
| スローオーバー                 | トレンドラインを超えて反転                   |
| フェイラー（トランケーション） | 5波が3波の高値を超えない                     |
| スラスト                       | 4波トライアングル後の5波が短時間で終わる現象 |

### ダイアゴナル関連

| 用語                     | 定義                         |
| ------------------------ | ---------------------------- |
| リーディングダイアゴナル | 波動の最初に出る（1波、A波） |
| エンディングダイアゴナル | 波動の最後に出る（5波、C波） |

### 複合修正波

| 用語               | 定義                                         |
| ------------------ | -------------------------------------------- |
| ダブルスリー（W3） | W-X-Yの3波構成                               |
| トリプルスリー     | W-X-Y-X-Zの5波構成                           |
| ダブルジグザグ     | 2つのジグザグが連結（535-X-535）             |
| X波                | 複合修正波をつなぐ波、複雑で大きいことが多い |

### フラットのバリエーション

| 用語               | 定義                                         |
| ------------------ | -------------------------------------------- |
| レギュラーフラット | B波がA波の始点近くまで戻る                   |
| 拡大型フラット     | B波がA波始点を超え、C波がA波終点を超える     |
| ランニングフラット | C波がA波終点まで届かない、強いトレンドの前兆 |
| C波巨大化フラット  | C波が延長（エンラージメントコレクション）    |
