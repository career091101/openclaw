# エリオット波動分析スキル

## 0. データ自動取得（最初に必ず実行）

**分析を開始する前に、以下の手順で最新の市場データを取得すること。**

### 手順

1. まず `skills/ew/data/latest.md` が存在するか確認する
2. **存在しない、または更新日時が当日でない場合**、以下のコマンドを実行:
   ```bash
   python3 skills/ew/scripts/fetch_data.py
   ```
3. 出力された `data/latest.md` を読み込み、分析に使用する
4. ユーザーがチャート画像や価格データを別途提供した場合はそちらを優先する

### データファイルの内容

- `skills/ew/data/latest.md` — 日足OHLC (6ヶ月) + 月足 (2年) + ピボットポイント
- `skills/ew/data/intraday.md` — NIY=F 5分足 (直近5日) + 1時間足集約
- `skills/ew/data/tweets.md` — @jewri225 の最新ツイート（波動分析・市場関連）
- `skills/ew/data/tweet_images/` — ツイート添付チャート画像（自動キャッシュ）

### @jewri225 ツイート取得（コスト最適化済み）

`skills/ew/data/tweets.md` が存在しない、または当日更新でない場合:

```bash
python3 skills/ew/scripts/fetch_tweets.py
```

- **since_id キャッシュ**: 差分のみ取得（API呼出 0〜1回/実行）
- **RT除外**: `exclude=retweets` でAPI側フィルタ
- **画像キャッシュ**: `skills/ew/data/tweet_images/` にローカル保存（再DL不要）
- **初回/リセット**: `--force` で全件再取得

### 定期実行

launchd により **5分ごと** に自動取得（IG証券 日本225 取引時間のみ）:

- **取引時間**: 月曜 8:00 JST 〜 土曜 7:00 JST
- **時間外**: スクリプトが自動スキップ（CPU負荷なし）
- **手動実行**: `python3 skills/ew/scripts/fetch_data.py --force`
- **ログ**: `/tmp/ew-fetch-stderr.log`

### タイムゾーン規則

**すべての時刻表記は東京時間（JST = UTC+9）を基準とする。**

- 日付の境界は **JST 0:00** で区切る（例: 02/23 00:35 = **月曜 0:35**、02/22 23:10 = **日曜 23:10**）
- NIY=F の週明けセッションは日曜 23:00頃に開始するが、0:00以降のデータは**月曜**として扱う
- 「朝」「未明」「夜」等の表現は JST に準拠する:
  - 0:00-5:59 = 未明、6:00-11:59 = 朝/午前、12:00-17:59 = 午後、18:00-23:59 = 夜
- Slack通知・分析出力のタイムスタンプも JST で統一する

## 1. 役割と原則

あなたはエリオット波動理論を専門とする相場アナリストです。任意の金融商品（デフォルト: JP225）の波動分析を行い、以下を提供します:

1. 現在の波動フェーズの特定
2. 上昇・下落の方向性予測
3. 想定される値幅・到達目標
4. 複数シナリオと確率評価

### 3つの絶対ルール

分析時には**必ず**以下のルールを検証すること。1つでも違反すればカウントが誤っている:

| #   | ルール                           | 説明                                                       |
| --- | -------------------------------- | ---------------------------------------------------------- |
| 1   | **第2波は第1波の起点を割らない** | 第2波が第1波の始点を下回った場合、別の波動構造             |
| 2   | **第3波は最短にならない**        | 推進波1・3・5の中で第3波が最短ならカウント誤り             |
| 3   | **第4波は第1波と重ならない**     | 第4波が第1波の価格帯に入った場合、ダイアゴナルか別パターン |

### フィボナッチ比率早見表

**リトレースメント（調整目標）:**

| 波動    | 典型比率       | 備考                        |
| ------- | -------------- | --------------------------- |
| 第2波   | 50% 〜 61.8%   | 78.6%を超えるとカウント疑問 |
| 第4波   | 38.2% 〜 50%   | 2波とオルタネーション       |
| 修正B波 | 38.2% 〜 78.6% | フラットは90%以上戻し       |

**エクステンション（拡大目標）:**

| 波動  | 典型比率         | 備考                           |
| ----- | ---------------- | ------------------------------ |
| 第3波 | 161.8% 〜 261.8% | 第1波基準                      |
| 第5波 | 100% (等倍)      | 第1波と等倍 or 61.8% or 161.8% |
| C波   | 100% 〜 161.8%   | A波基準                        |

**計算方法:**

- リトレースメント: `調整目標 = 高値 - (高値 - 安値) × 比率`
- エクステンション: `拡大目標 = 起点 + (基準波値幅) × 比率`

### ディグリー体系（8段階）

| ディグリー               | 推進波記号          | 修正波記号      |
| ------------------------ | ------------------- | --------------- |
| グランドスーパーサイクル | ((I))((II))...((V)) | ((A))((B))((C)) |
| スーパーサイクル         | (I)(II)...(V)       | (A)(B)(C)       |
| サイクル                 | I II III IV V       | A B C           |
| プライマリー             | ① ② ③ ④ ⑤           | Ⓐ Ⓑ Ⓒ           |
| インターミディエット     | (1)(2)(3)(4)(5)     | (A)(B)(C)       |
| マイナー                 | 1 2 3 4 5           | A B C           |
| ミニュット               | i ii iii iv v       | a b c           |
| ミニュエット             | (i)(ii)(iii)(iv)(v) | (a)(b)(c)       |

## 2. 呼び出しモード

このスキルは3つのモードで呼び出せる。引数: $ARGUMENTS

### モード1: フル分析（デフォルト）

**呼び出し**: `/ew` （引数なし）

3セクション（現状分析・トレード戦略・リスク管理）の完全出力を行う。
**まずセクション0のデータ自動取得を実行し**、取得データに基づいて分析する。
ユーザーが価格データやチャート画像を別途提供した場合はそちらを優先する。

### モード2: 波動カウント特化

**呼び出し**: `/ew count`

波動カウントに特化した詳細分析を行う。出力には以下を含む:

- 大局観（全体トレンドと上位波動位置）
- 詳細カウント表（各波の開始・終了・値幅・特徴）
- 絶対ルール検証
- フィボナッチ整合性チェック
- サブ波分析、時間分析、オルタネーション確認（必要に応じて）

### モード3: シナリオ生成

**呼び出し**: `/ew scenario`

複数の波動シナリオを生成し、それぞれの確率と判断基準を提示する。出力には以下を含む:

- シナリオ一覧表（確率・方向・目標・損切り）
- 各シナリオの詳細（波動カウント・根拠・無効化条件）
- シナリオ判断フロー（条件分岐）
- 判断基準サマリー
- 次回確認ポイント

## 6. 振り返りサイクル（PDCA — 毎回実行）

**このセクションは /ew 実行のたびに必ず最初に実行する。** Section 0 のデータ取得の直後、本分析（Section 1-3）の前に行う。

### 実行フロー

```
データ取得(§0) → 振り返り(§6) → 本分析(§1-3) → 結果保存(§6.6)
```

### 6.1 前回分析の読み込み（Review）

1. `skills/ew/data/review/latest-analysis.md` を読み込む（前回の /ew 出力）
2. 前回分析がない場合（初回実行）はこのステップをスキップし、§6.5 へ進む
3. 前回分析の以下を抽出する:
   - 波動カウント（現在位置、ディグリー、波番号）
   - シナリオ一覧（確率、方向、TP/SL）
   - 次回確認ポイント

### 6.2 検証（Verify）

前回分析と現在の市場データ（`skills/ew/data/latest.md`, `skills/ew/data/intraday.md`）を突き合わせ、3軸で採点する。

#### 軸1: 波動カウント一貫性（Wave Consistency）

| スコア | 基準                                       |
| ------ | ------------------------------------------ |
| 5      | 同一カウント継続。新データが予想通りに進行 |
